Kalibrieren

Am schnellsten: Auf „Kalibrieren“ tippen und dann die tiefste Taste (A0) am Piano drücken. Der Versatz wird automatisch berechnet.

Pedal-Hack

Kalibrierung per Pedal starten

Das Pedal mehrmals schnell hintereinander treten, dann die tiefste Taste drücken. So geht Transpose ohne Handy.

Automatisch vom Piano (Roland SysEx)

Transpose vom Piano übernehmen

Einrichten (Lernfunktion)

Voraussetzung: Am RD-700NX muss „Tx Edit Data“ (System/MIDI) eingeschaltet sein. Ablauf: 1) Am Piano Transpose auf 0 stellen, „Start“ tippen. 2) Transpose auf +1 stellen, „Nächster Schritt“. 3) Transpose auf +2 stellen, „Nächster Schritt“. 4) „Fertig“.

LED-Streifen

Richtung umkehren (LED 0 am hohen Ende)

Testen

A0·C4·C8: Leuchten die LEDs über der tiefsten Taste, dem mittleren C und der höchsten Taste? Wenn nicht, Versatz und LED-Abstand anpassen. Rot/Grün/Blau: Zeigt der Streifen die Farben in dieser Reihenfolge? Sonst Farbreihenfolge ändern.

Strom

Schutz vor Spannungseinbrüchen: Übersteigt der geschätzte Strom das Limit, wird der Frame automatisch gedimmt. 0 = aus. Bei einem 3-A-Netzteil ca. 2500 eintragen.

Hardware

Änderungen an GPIO oder LED-Anzahl werden erst nach einem Neustart des Dienstes wirksam (System → Dienst neu starten).
