Hotspot

Findet der Visualizer kein bekanntes WLAN, öffnet er diesen Hotspot. Das Handy zeigt dann automatisch die Einrichtung an. Name und Passwort stehen auch auf dem Display.

Testen

„3 Tasten“ lässt die LEDs über der tiefsten Taste, dem mittleren C und der höchsten Taste leuchten. Sitzen sie daneben, stelle unten Versatz und LED-Dichte ein. „Farben“ muss nacheinander Rot, Grün und Blau zeigen, sonst die Farbreihenfolge ändern.

Streifen

Strom

Bevor die Stromaufnahme dieses Limit übersteigt, wird automatisch gedimmt. So bleibt die Spannung stabil und der Pi stürzt nicht ab. Für ein 3-A-Netzteil sind 2500 mA ein guter Wert, 0 schaltet den Schutz ab.

Anschluss

Änderungen an Pin und LED-Anzahl gelten nach einem Neustart des Dienstes.

Mit dem Pedal erkennen

Tritt das Pedal schnell hintereinander und drück dann die tiefste Taste. So stellst du Transpose ohne Handy ein.

Direkt vom Piano übernehmen

  1. Am RD-700NX unter System → MIDI „Tx Edit Data“ einschalten.
  2. Transpose am Piano auf 0 stellen, dann Start tippen.
  3. Transpose auf +1 stellen, Weiter tippen. Dann auf +2, wieder Weiter.
  4. Fertig tippen. Ab jetzt folgen die LEDs dem Piano.

Zusatzfunktionen sind ausgeschaltet, bis du sie hier aktivierst.

Jeder Tritt schaltet zum nächsten gespeicherten Preset.
